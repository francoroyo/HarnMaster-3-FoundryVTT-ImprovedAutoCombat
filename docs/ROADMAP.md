# Roadmap

## Milestone 1 - Foundation (complete)

- Foundry v14 module manifest and HM3 dependency
- Compatibility diagnostics
- Combat hook bridge and bounded workflow events
- Public API and pure modifier helpers
- Automated tests and manifest validation

## Milestone 2 - Deferred impact rolls (complete)

- Capture-scoped Dodge, Block, Ignore, and Counterstrike override
- Pending impact cards with editable d6 count and additional impact
- One-shot finalized rolls with HM3-compatible injury actions
- Owner/GM authorization, socket authority, leases, and reload recovery
- Compatibility fallback and automated card/state/controller tests

## Milestone 3 - Workflow model

- Correlate attack declaration, chosen defense, result, and injury into one transaction
- Handle tactical advantages without allowing more than one per character turn
- Add GM-visible diagnostics for incomplete or stale workflows
- Test melee, missile, simultaneous strike, block, miss, fumble, and stumble paths

## Milestone 4 - Additional combat assistance

- Defense eligibility suggestions based on attack type and combat state
- Modifier preview with an explainable breakdown
- Guided strike delivery from combat result to hit location, armour, and injury

## Milestone 5 - Hardening and release

- Foundry integration test world and manual test matrix
- Accessibility and localization pass
- Release packaging and manifest URLs
- Compatibility checks against each supported HM3 release
