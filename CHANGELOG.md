# Changelog

All notable changes to this project will be documented here.

## 0.2.0 - 2026-09-01

- Replace immediate automated impact rolls with pending **Roll Impact** result cards.
- Add an editable Foundry v14 dialog for d6 count and additional impact.
- Preserve HM3 combat resolution and restore its injury action after one-shot finalization.
- Add libWrapper-scoped roll interception, native socket GM authority, 30-second claims, and expired-lease recovery.
- Add versioned impact flags, public impact APIs and hooks, compatibility fallback, styling, documentation, and tests.

## 0.1.0 - 2026-09-01

- Initialize the Foundry VTT v14 module manifest.
- Add an observer adapter for Valcorin's HarnMaster 3 combat hooks and macro API.
- Add an in-memory combat workflow event stream and public module API.
- Add pure, tested helpers for common HarnMaster combat modifiers.
- Add validation, tests, architecture notes, and an implementation roadmap.
